## 为什么归档

这里装着终端服务部早期的资料：部门介绍、学习路线、教学纪要、若干教程。有价值的是内容，问题在结构——没有目录规范、没有校验、没有检索入口，新人打开不知道从哪看起。

这些内容现在按《实验室技术知识库文档写入规范》重新组织过，落在 `lab-terminal-service` 的「终端服务部」一章里，有统一的 front-matter、有 CI 校验、有站内搜索。
